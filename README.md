# 🚀 Web Development IDE

Modern IDE for HTML, CSS, and JavaScript with AI assistance.

## ✨ Features

- 📝 Multi-tab editor with advanced syntax highlighting
- 🎨 **6 Beautiful Color Themes** (VS Code Dark+, Monokai, Dracula, One Dark, GitHub Dark, Tokyo Night)
- 🤖 AI assistant (Ollama/Qwen/OpenAI)
- 📁 File explorer
- 👁️ Live preview
- 💻 Built-in terminal
- ✨ Code polishing with animated overlay

## 📦 Quick Start

### Install

```bash
pip install -r requirements.txt
```

### Run

```bash
python WebDevelopmentIDE.py
```

### Build Executable

```bash
build.bat
```

Creates: `dist\WebDevelopmentIDE.exe`

## 📁 Files

- **WebDevelopmentIDE.py** - Main application
- **build.bat** - Quick build script
- **build_secure.py** - Interactive build with options
- **icon.ico** - App icon
- **splash.png** - Splash screen
- **THEMES.md** - Color theme guide (import VS Code/Sublime/JetBrains themes)
